# Dateien für Google Apps Script

- `Code.gs` → im Apps-Script-Projekt die Datei **Code.gs** ersetzen
- `Index.html` → im Apps-Script-Projekt die Datei **Index** ersetzen (nur für die Browser-Version nötig; die Android-App hat die Oberfläche eingebaut)

Danach: **Bereitstellen → Bereitstellungen verwalten → Stift → Version: Neue Version → Bereitstellen**.

Zum Kopieren am Handy die Rohfassung öffnen:
- https://raw.githubusercontent.com/Cokakula/familienstammbaum-app/main/google/Code.gs
- https://raw.githubusercontent.com/Cokakula/familienstammbaum-app/main/google/Index.html
